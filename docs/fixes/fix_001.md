El fix consiste en que al crear una nueva competición o un matchday he visto que redirige a la pagina de detalle de la competición o matchday, sin embargo, devuelve un error 404 porque no construye correctamente la URL de redirección.

Ejemplo de url valida para una competicion.
dashboard/competitions/1764789084543-zetn2uv

Cuando cree esta cometición me redirigió a:
competitions/1764789084543-zetn2uv/
y como resultado devolvió un 404.

Tu tarea es arreglar este bug para que redirija correctamente a la URL sin la barra final.
